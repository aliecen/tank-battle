# 坦克大战 (Tank Battle)

经典 FC 坦克大战网页版，纯 HTML/CSS/JS 实现。

## 游戏玩法

- **移动**: 方向键 ↑↓←→ 或 WASD
- **射击**: 空格键 或 J
- **重新开始**: 按 R 键

## 游戏特性

- 经典坦克大战玩法
- 砖墙可被子弹摧毁，钢墙不可摧毁
- 击杀敌人有概率掉落道具：生命 ♥、护盾 🛡、加速 ⚡
- 多关卡，难度递增
- 屏幕震动效果
- 粒子爆炸特效

## 运行方式

直接用浏览器打开 `index.html` 即可开始游戏。

或者使用任意 HTTP 服务器：

```bash
npx serve .
```
